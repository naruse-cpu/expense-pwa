# 経費・報告書PDF作成 PWA

## GitHub Pages 公開手順
1. GitHubで新規 **Public** リポジトリを作成（例 `expense-pwa`）。公開リポジトリに社内秘密情報を入れないでください。
2. このZIPを展開し、`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` をリポジトリのルートにアップロード。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択。Branch は `main`、フォルダは `/(root)` を選択し保存。
4. 表示された `https://ユーザー名.github.io/expense-pwa/` にスマホでアクセス。
5. iPhone: Safariの共有メニューから「ホーム画面に追加」。Android: Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」。

## 仕様
- 画像・PDFの合計5ファイルまで追加。PDFは全ページ結合。画像はA4に1枚ずつ配置。
- スキャン・電子: 金額、勘定科目、支払い区分を入力。部署と名前は端末内のlocalStorageに保存。
- 点検報告・作業報告: ユーザー名（必須）、自由欄。
- 出力名は既存Windows版と同じ規則。日付はスマホの当日を初期表示。
- 画像・PDFの内容はブラウザ内で処理し、サーバーにはアップロードしません。
- PDF生成に `pdf-lib` 1.17.1 をCDNから読み込みます。初回利用にはインターネットが必要です。キャッシュされればオフラインでも使える場合がありますが、完全なオフライン保証はありません。
- カメラ撮影・画像ファイルはブラウザが扱える形式が対象です。HEIC等は機種・ブラウザにより非対応の可能性があります。暗号化PDFは非対応です。
- iOSではダウンロード時に「ファイル」アプリへの保存操作が必要になる場合があります。「共有」ボタンも利用できます。

## 注意
GitHub Pagesのアプリコードは公開されます。画像・PDFはブラウザで処理し、ファイルのアップロード先はありませんが、機密書類を扱う場合は社内の利用規程を確認してください。CDNへのライブラリ取得通信は発生します。


## Ver.2: 書類の自動トリミング

1. 写真を追加（PDFファイルそのものはトリミング対象外）。
2. 写真の横にある「トリミング」をタップ。
3. 自動で紙の輪郭を検出。うまく検出できない場合は青い4点を指で調整。
4. カラー／グレースケール／白黒を選び「補正を確定」。
5. PDFを作成すると補正後の画像が使われます。「元画像に戻す」で取消可能。

**制限:** 自動検出は照明、背景、紙の色に左右されます。OpenCV.jsをインターネットから初回読み込みするため、トリミングにはネット接続が必要です。iPhoneのSafari等での実機動作は未検証です。写真とPDFは外部に送信しませんが、OpenCV.jsとpdf-libのライブラリコードは外部CDNから取得します。GitHub Pagesに同名ファイルをすべて上書きし、更新後はブラウザを再読み込みしてください。

## Ver.3 修正
- iPhoneで「補正を確定」が進まない問題への対策として、補正確定時の画像処理をOpenCV.js依存からブラウザ標準Canvasへ変更しました。
- 自動四隅検出のみOpenCV.jsを使用。検出できない場合も四隅を手動調整して補正確定できます。
- 同名ファイルをGitHubのルートに上書きしてコミットしてください。PWAの更新は再起動やSafari再読み込みが必要な場合があります。
